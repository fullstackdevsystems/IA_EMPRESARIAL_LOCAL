# R9.7 — Generic Prompt Execution Plan + Dynamic Components

Este parche actualiza IA Empresarial Local desde R9.6 a 8.5.5-r9.7.

Incluye:
- plan de ejecución estructurado y auditable derivado del prompt;
- validación de requisitos contra columnas reales;
- cobertura porcentual del prompt;
- TD/resumen dinámico por cliente;
- reportes derivados por cualquier `ctrl_alm`;
- rankings reactivos por vendedor, zona, categoría, proveedor y almacén;
- análisis de fletes y mermas;
- oportunidades/alertas determinísticas;
- componentes que reaccionan a filtros;
- clasificación explícita de requisitos listos, parciales o no soportados;
- versión coherente R9.7.

No se inventan datos ni columnas. Preguntas naturales dentro del HTML y exportación XLSX quedan identificadas como no soportadas en esta etapa.
