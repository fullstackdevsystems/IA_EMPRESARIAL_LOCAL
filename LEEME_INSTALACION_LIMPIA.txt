IA EMPRESARIAL LOCAL

INSTALACIÓN COMERCIAL

Extrae el paquete completo y ejecuta INSTALAR_IA_EMPRESARIAL_LOCAL.bat.
El instalador verifica la integridad del paquete y prepara una instalación local
aislada. No reutiliza datos, credenciales ni secretos de otra instalación.

PRIMER USO

La configuración normal se realiza desde la interfaz local y no requiere
PowerShell ni identificadores técnicos.

1. Abre la interfaz local después de finalizar la instalación.
2. En "Configura tu empresa", registra el nombre de la empresa y crea la cuenta
   del administrador inicial con una contraseña segura.
3. En Administración, utiliza "Conectar SQL Server" para probar la conexión,
   descubrir los objetos disponibles y seleccionar las tablas autorizadas.
4. En "Configurar inteligencia artificial", elige Ollama local, un servidor
   local compatible o "Continuar sin IA". La inteligencia artificial es
   opcional. Si la habilitas, primero prueba la configuración y después guarda.
5. Selecciona "Validar preparación". El sistema mostrará "Listo" únicamente
   cuando el servidor confirme que los requisitos activos están preparados.

La configuración avanzada permanece disponible para administración y soporte,
pero no es necesaria para completar el recorrido normal de puesta en marcha.

OPERACIÓN

Para el uso diario utiliza la interfaz local. OperarIA.ps1 queda disponible como
herramienta de soporte para iniciar, detener, consultar estado, validar,
diagnosticar, respaldar y restaurar la instalación. Los diagnósticos sanitizan
credenciales, tokens y secretos conocidos.

SOLUCIÓN DE PROBLEMAS

SI LA INSTALACIÓN FALLA

El instalador se detiene cuando una comprobación obligatoria falla y muestra un
mensaje "FAIL" con la causa detectada. No considere terminada una instalación
que haya finalizado con ese mensaje.

Conserve el mensaje completo mostrado por el instalador para soporte. En una
actualización, los mecanismos de instalación protegen el runtime administrado y
restauran los componentes anteriores cuando falla una etapa gobernada. No copie
manualmente archivos de otra instalación ni reutilice credenciales o secretos
para intentar completar una instalación fallida.

Si necesita escalar el problema, indique a soporte el mensaje "FAIL", la etapa
en la que ocurrió y la versión que intentaba instalar. No comparta contraseñas,
tokens ni secretos.

READINESS: DEGRADED

"READINESS: DEGRADED" no significa necesariamente que el runtime esté detenido.
El servicio puede estar activo pero tener algún requisito configurado que todavía
no está preparado.

Utiliza OperarIA.ps1 para soporte con estas acciones:

  .\OperarIA.ps1 -Action status
  .\OperarIA.ps1 -Action validate
  .\OperarIA.ps1 -Action diagnostics

Revisa también en la interfaz local la configuración activa de SQL Server y de
inteligencia artificial. La IA es opcional: si la organización no la utilizará,
puede continuar con IA deshabilitada mediante el flujo gobernado de configuración.

Después de corregir la causa, vuelve a ejecutar la validación de preparación.
El estado "Listo" debe provenir de la validación del servidor; no debe asumirse
manualmente.

Si el problema continúa, genera el paquete sanitizado para soporte:

  .\OperarIA.ps1 -Action diagnostic-bundle

El paquete de diagnóstico aplica sanitización de credenciales, tokens y secretos
conocidos antes de prepararse para soporte.

RECUPERACIÓN Y SOPORTE

Antes de cambios importantes, crea un respaldo gobernado de la instalación.
Los respaldos incluyen el estado persistente administrado, pero no incorporan
los secretos locales de ejecución.

Para restaurar, utiliza únicamente un respaldo conocido y autorizado. El sistema
valida la estructura y la integridad del archivo antes de aplicar la recuperación.
Un respaldo corrupto, inseguro o inválido se rechaza. Si una restauración falla
durante el proceso, el mecanismo de recuperación protege el estado válido previo
en lugar de aceptar silenciosamente un estado parcial.

Para soporte técnico, OperarIA.ps1 permite consultar estado, validar la
instalación, ejecutar diagnósticos y generar un paquete de diagnóstico sanitizado.
La ayuda integrada del script muestra la sintaxis y ejemplos de respaldo,
restauración y diagnóstico.

SEGURIDAD

No comparta contraseñas, tokens, archivos de configuración ni respaldos fuera de
los procedimientos autorizados de su organización.
