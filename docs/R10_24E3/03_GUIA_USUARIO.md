# IA Empresarial Local — Guía de usuario

Versión del producto: 8.5.5
Documentación: R10.24E3

## Objetivo

Utilizar IA Empresarial Local sin conocimientos de programación, Python, PowerShell, APIs o administración técnica.

## Inicio

Ruta principal:

    /app

Inicio concentra el acceso a las funciones disponibles según el rol del usuario.

## Asistente

Ruta:

    /assistant

Permite hacer preguntas en lenguaje natural sobre información empresarial autorizada.

Ejemplos:

- ¿Cuánto vendimos este mes?
- ¿Cuáles son los principales clientes?
- ¿Qué productos están disminuyendo?
- Resume los indicadores importantes.

Las cifras deben proceder de datos gobernados o cálculos determinísticos disponibles.

## Analizar

Ruta:

    /analyze

Flujo:

1. Selecciona un archivo soportado.
2. Describe el análisis requerido.
3. Ejecuta el análisis.
4. Revisa los resultados.
5. Descarga los entregables disponibles.

El producto puede generar dashboard HTML, PDF y Excel de acuerdo con el flujo ejecutado.

## Datos

Ruta:

    /data

Muestra las fuentes empresariales disponibles y las opciones permitidas para conectarlas.

## Reportes

Ruta:

    /reports

Permite consultar y Descargar reportes previamente generados.

Los entregables persistentes continúan disponibles después de reiniciar el servicio mientras su estado permanezca íntegro.

## Configuración

Ruta:

    /settings

Las opciones disponibles dependen de los permisos del usuario.

## Inicio de sesión

Utiliza únicamente tu usuario y contraseña asignados.

No compartas tu contraseña y cierra sesión al utilizar equipos compartidos.

## Permisos

Si una función no aparece o devuelve acceso denegado, solicita al administrador revisar tu rol y alcance.

No utilices las credenciales de otro usuario para evitar restricciones.
