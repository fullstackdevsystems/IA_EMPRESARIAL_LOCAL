IA EMPRESARIAL LOCAL V8.5.5 R7
INSTALACION COMPLETA LIMPIA

Esta carpeta contiene la aplicacion base completa de IA Empresarial Local.
No contiene datos, memoria, documentos, reportes, logs, tokens, secretos ni entornos virtuales de otra instalacion.

INSTALACION RECOMENDADA
Utiliza el archivo INSTALAR_IA_EMPRESARIAL_LOCAL.bat que se encuentra un nivel arriba de esta carpeta dentro del ZIP completo.

Si copias manualmente esta carpeta:
1. Debe quedar exactamente como C:\IA_Local.
2. Ejecuta C:\IA_Local\INSTALAR_Y_ABRIR.bat como Administrador.
